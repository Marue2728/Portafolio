Sistema de Gestión de Ventas y Facturación
Angular Node.js Express JSON Server JWT

Aplicación web completa para la gestión integral de ventas y facturación. Este sistema permite administrar órdenes, facturas, usuarios, pagos y generar reportes detallados, todo con un robusto sistema de autenticación y control de usuarios activos.

🚀 Ver video del proyecto
📥 Descargar Sistema de Gestión

✨ Características Principales

  • Autenticación JWT: Sistema de login y registro seguro con tokens de autenticación
  • Gestión de Usuarios: Control de usuarios activos con registro de hora de login
  • Órdenes y Facturas: CRUD completo para crear, editar y eliminar documentos comerciales
  • Cálculos Automáticos: Sistema inteligente de autocálculo de impuestos y totales
  • Métodos de Pago Múltiples: Soporte para efectivo, tarjeta, Bitcoin, Chivo Wallet y pagos mixtos
  • Estado de Facturación: Cambio automático y manual del estado de las facturas
  • Persistencia de Datos: Almacenamiento confiable con JSON Server
  • Rutas Protegidas: Guards de autenticación y prevención de pérdida de datos

🛠️ Arquitectura Técnica

  • Frontend: Desarrollado en Angular con enlace bidireccional mediante ngModel
  • Backend: Servidor Express con API REST en Node.js
  • Base de Datos: JSON Server para prototipado rápido y desarrollo ágil
  • Seguridad: Implementación de AuthGuard y CanDeactivateGuard
  • Navegación: Sistema de rutas con sidebar dinámico para mejor UX
02
Interfaz Web para Chat con Ollama
Python Bottle Ollama JavaScript HTML/CSS

Sistema de chat inteligente que integra modelos de lenguaje local mediante Ollama. Permite mantener conversaciones con IA de forma fluida, con soporte para personalidades personalizadas y gestión completa de sesiones persistentes.

🚀 Ver video del proyecto
📥 Descargar Interfaz Web

✨ Características Principales

  • Chat en Streaming: Respuestas en tiempo real con visualización progresiva del texto
  • Persistencia de Conversaciones: Todas las sesiones se guardan automáticamente en formato JSON
  • Reanudación de Chats: Capacidad de retomar conversaciones anteriores con todo el contexto preservado
  • Sistema de Personalidades: Creación, edición y gestión de diferentes comportamientos del asistente
  • Selección de Modelos: Interfaz para elegir entre diferentes modelos de Ollama disponibles
  • Síntesis de Voz: Lectura en voz alta de respuestas (compatible con Termux en Android)
  • Interfaz Dinámica: Gifs animados que cambian según el estado de ánimo detectado en las respuestas

🛠️ Funcionalidades Técnicas

  • Backend Python: Servidor ligero construido con framework Bottle
  • Integración Ollama: Comunicación directa con modelos LLM locales mediante API
  • Gestión de Sesiones: Sistema de archivos JSON en carpeta history/ para almacenamiento
  • Personalidades Editables: Archivos .txt en carpeta personalities/ para instrucciones del bot
  • Análisis de Emociones: Detección de palabras clave para cambiar la presentación visual
  • Panel de Control: Menú lateral con todas las opciones de configuración y gestión

🎯 Casos de Uso

  • Asistente personal con diferentes personalidades (sabio, serio, divertido, etc.)
  • Herramienta de aprendizaje con contexto persistente
  • Sistema de consultas técnicas con historial completo
  • Experimentación con diferentes modelos de IA local sin depender de APIs externas

✨ Características del Juego

  • LocalStorage API: Persistencia del récord de puntuación
  • Touch Events: Controles táctiles para dispositivos móviles
  • RequestAnimationFrame: Bucle de juego optimizado para 60fps

Gestor de Facturas - Python + Tkinter + SQLite + PDF
Python Tkinter SQLite FPDF PyInstaller

Aplicación de escritorio completa para la gestión y generación de facturas profesionales. Desarrollada en Python con interfaz gráfica Tkinter, base de datos SQLite y generación automática de PDFs. Permite gestión de clientes, productos, historial completo y personalización con logo.

🚀 Ver video del proyecto
📥 Descargar Generador de Facturas

✨ Características Principales

  • Generación automática del número de factura con secuencia incremental
  • Fecha automática con posibilidad de edición manual
  • Base de datos SQLite para almacenamiento local y persistente
  • Generación de PDFs profesionales con diseño limpio y estructurado
  • Logo personalizable que se guarda permanentemente en la aplicación
  • Historial completo de todas las facturas generadas
  • Cálculo automático de subtotal, IVA y total
  • Interfaz gráfica intuitiva desarrollada con Tkinter
  • Compatibilidad multiplataforma (Windows, Linux, Android/Termux)

🛠️ Arquitectura Técnica

  • Frontend: Interfaz gráfica con Tkinter (incluido en Python)
  • Base de Datos: SQLite3 para almacenamiento local eficiente
  • Generación de PDF: Biblioteca FPDF2 para documentos profesionales
  • Persistencia de Configuración: Archivo JSON para guardar preferencias y logo
  • Empaquetado: PyInstaller para crear ejecutables .EXE
  • Estructura de Archivos: Organización modular y mantenible

📁 Estructura del Proyecto

  • facturas.py - Aplicación principal
  • facturas.db - Base de datos SQLite
  • config_logo.json - Configuración y logo personalizado
  • invoices/ - Carpeta de PDFs generados
  • requirements.txt - Dependencias del proyecto

🎯 Funcionalidades Avanzadas

  • Gestión de Logo: Selección de archivos PNG/JPG/JPEG que persiste entre sesiones
  • Número de Factura Automático: Sistema incremental que evita duplicados
  • Plantilla PDF Profesional: Diseño limpio con todos los datos requeridos
  • Búsqueda y Filtrado: Capacidad de consultar facturas anteriores
  • Exportación a EXE: Conversión a ejecutable standalone con PyInstaller
  • Validación de Datos: Verificación de campos obligatorios y formatos
  • Backup Automático: La base de datos se mantiene automáticamente

🔧 Tecnologías Utilizadas

  • Python 3.8+ - Lenguaje de programación principal
  • Tkinter - Framework para interfaz gráfica
  • SQLite3 - Base de datos embebida
  • FPDF2 - Generación de documentos PDF
  • PIL (Pillow) - Procesamiento de imágenes para logos
  • PyInstaller - Empaquetado para distribución
  • JSON - Configuración y persistencia de settings
